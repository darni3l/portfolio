# Editing content

Everything shown on the site lives in this folder. Components never contain copy.

- Text may contain `*italic*` (rendered as <em>), e.g. `*Physcomitrium patens*`.
- Image paths are relative to `public/` (e.g. `images/projects/case-01.png`).
  Leave `src: null` to show a labelled placeholder.
- After changing a field, the site updates on save (`npm run dev`).
